Please credit **hideouts-io**, identify this repository as the source, link the license, and indicate changes to adapted material. The license applies only to rights the project can grant.

Links to Apple, UEFI, Microchip, GitHub projects and other research remain under their respective owners' terms. Factual measurements and hashes do not become proprietary to this project merely by appearing in a CC BY 4.0 table.

[Creative Commons recommends software-specific licenses for code](https://creativecommons.org/faq/#can-i-apply-a-creative-commons-license-to-software). The owner chose CC BY 4.0 for the original scripts here as part of one research repository; the license has no software-specific source-distribution or patent terms. A future code-license change should be explicit and should not silently relicense external material.
